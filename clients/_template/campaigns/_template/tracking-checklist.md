# Tracking Checklist

## Pre-Launch

- [ ] Landing page loads
- [ ] Primary conversion event verified
- [ ] Pixel or analytics source verified
- [ ] UTM parameters verified
- [ ] Destination URL verified

## Post-Launch

- [ ] Impressions confirmed
- [ ] Clicks confirmed
- [ ] PageView or landing event confirmed
- [ ] Conversion event confirmed
- [ ] Any ignored events excluded from reporting

## Notes

Record what is verified, what is not available, and what remains manual.
